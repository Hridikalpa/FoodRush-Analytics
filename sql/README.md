# SQL Investigation Layer

The SQL folder contains the business investigation layer of FoodRush Analytics.

| Ticket | Investigation |
|---:|---|
| 1 | Top acquisition channels by customer value |
| 2 | Repeat customer rate by city |
| 3 | Month-over-month revenue growth |
| 4 | Revenue decomposition analysis |
| 5 | Top 3 customers city-wise |
| 6 | Customer revenue concentration / Pareto analysis |
| 7 | Customers spending above city average |
| 8 | Customers without delivered orders |
| 9 | Month-to-month customer retention |
| 10 | Monthly customer churn |
| 11 | Customer purchase behaviour with advanced window functions |
| 12 | Customer value ranking and executive segmentation |
| 13 | Customer lifecycle segmentation |
| 14 | Restaurant performance intelligence and segmentation |

The sequence moves from basic KPI questions toward increasingly diagnostic and segmentation-oriented analysis.
